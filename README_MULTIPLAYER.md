# Important: How to use Online Mode

## Firebase Setup:

You will need a Firebase Project ID and a Web API Key.

Go to the Firebase Console.

Create a project, enable Firestore Database (start in Test Mode for simplicity).

Go to Project Settings to find your Web API Key and Project ID.

## In the App:

Select "Online Multiplayer" in the sidebar.

Enter your credentials.

Player 1: Click "Create New Game". Copy the Game ID.

Player 2: Paste the Game ID and click "Join Game".
